找靓机筛选

找靓机 App 悬浮球 · 搜索列表拉全 + 验机报告同源显示

给「找靓机」App 挂一个悬浮球，搜索后长按悬浮球（或点面板「开始抓取」）按页把搜索结果拉全， 悬浮球实时显示已抓条数；抓完按机型 / 内存 / 电池 / 系统版本 / 成色筛选，支持价格排序与复制链接。 首页推荐流不抓不入库，只在你主动触发时抓当前搜索结果。

它做什么

  • 悬浮球交互：点一下只展开面板；长按悬浮球或点面板「开始抓取」才真正去抓，开始时会震动两下提示。
  • 按页拉全：搜索后手动触发，按页向下拉取直到没有新数据，条数实时显示在悬浮球上。
  • 点行看本条：成色 / 功能 / 外观 N 项使用痕迹与列表完全同源（都来自找靓机验机报告）， 不会再出现「列表写 95 新、点开网页变 99 新」的错位。
  • 筛选与排序：按机型 / 内存 / 电池 / 系统版本 / 成色筛选，一键切「价格低→高」「价格高→低」。
  • 复制与打开：「网页详情」走带登录态的内置 WKWebView，可复制单条链接或一键复制全部。

怎么用

1. 打开找靓机 App，搜索想要的关键词，屏幕边缘出现悬浮球。

2. 长按悬浮球（或点开面板后点「开始抓取」），手机会震两下表示开始抓取。

3. 抓完点悬浮球展开面板，设筛选条件、切价格排序；点行查看本条数据，或复制链接。
