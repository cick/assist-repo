钉钉助手

定时自动打卡 · 多时间段 · 秒级精度

功能

  • 多时间点：早上上班、晚上下班各设一条，最多 8 条；每条可单独开关，左滑删除。
  • 精确到秒：时 / 分 / 秒三列滚轮，到点后 0.25 秒内拉起钉钉。
  • 自动点击：自动进入「工作台 → 考勤打卡」，点中圆形打卡按钮（含 H5 / 小程序页面的 JS 点击）。
  • 只点一次：点中即冻结，进入拍照 / 填备注环节后不再重复点击，留给你手工完成。
  • 结果验证：只有页面真的出现「打卡成功 / 已打卡」才记成功，绝不假报。
  • 桌面悬浮球：单击＝拉起并打一次卡；长按＝只打开钉钉。可拖动、松手吸附边缘。
  • 多企业：账号挂多个企业时，自动识别「选择打卡企业」弹层并按设置序号点选。

安装

1. 在 Sileo / Zebra / Cydia 添加源
https://cick.github.io/assist-repo/

2. 安装 钉钉助手（会自动装好设置页与点击器模块）。

3. 装完无需手动操作：包内 postinst 会结束钉钉进程，下次打开钉钉时点击器自动注入。

若单独更新了「钉钉点击器」包，同样会在下次启动钉钉时生效。

使用

  • 打开 设置 → 钉钉助手，打开「启用定时打卡」。
  • 在「打卡时间」里点任一条，拨动时 / 分 / 秒三列滚轮，改完自动保存；点「＋ 添加时间」可加第二条。
  • 右侧开关可单独暂停某一条；向左滑动可删除。
  • 「重复」选工作日或每天；「默认打卡企业」多企业账号按序号选。
  • 不确定能否点中时，先点「立即测试」或双击悬浮球跑一遍，再点「查看调试日志」看每一步。
